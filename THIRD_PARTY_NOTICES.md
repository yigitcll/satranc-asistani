# Üçüncü taraf bileşen bildirimleri

## Stockfish

Bu uygulama Stockfish satranç motorunu kullanır. Motorun kaynak dosyaları ve GPL-3.0 lisans metni `stockfish/` klasöründedir. Git deposunda motorun Windows `.exe` ikilisi tutulmaz; çalıştırmak için Stockfish'in resmî indirme sayfasından Windows sürümünü alıp `stockfish/` klasörüne yerleştirin. Resmî kaynak ve indirmeler: <https://github.com/official-stockfish/Stockfish> · <https://stockfishchess.org/download/>.

## python-chess

Python bağımlılığı `requirements.txt` içinde sürümü sabitlenmiş `python-chess` paketidir. Paket GPL-3.0-or-later lisanslıdır. Proje ve lisans bilgileri: <https://github.com/niklasf/python-chess> · <https://python-chess.readthedocs.io/>.

## Bu proje

Uygulamanın kendi kodu da GNU GPL-3.0-or-later koşullarıyla yayımlanır. Tam lisans metni [`LICENSE`](LICENSE) dosyasındadır.
